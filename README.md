# Neural Networks: Zero to Hero

My work through Andrej Karpathy's
[Zero to Hero](https://karpathy.ai/zero-to-hero.html) series: each model
coded along with the video, rewritten from memory the next morning, and
extended with the exercises.

| project | content |
|---|---|
| [`micrograd/`](micrograd) | scalar autograd engine and a small neural network library, tested against PyTorch |
| [`makemore/`](makemore) | character-level language models: bigram, trigram, MLP |
